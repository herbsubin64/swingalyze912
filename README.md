# Swingalyze Flat Baseline

Baseline: video upload, playback, proper sizing.
Added: simple pose analysis overlay using MediaPipe.

## Usage
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
bash run_server.sh
```
Then open the port 8000 URL (e.g., https://8000-<CODESPACE_NAME>.github.dev/).

# Swingalyze Coach v2.4.0 — Full Rewrite (2025-09-19)

Adds on-canvas angle readouts, richer cues/drills, and a consolidated PNG report.
API remains the same as v2.3.0 (`/api/status`, `/api/analyze?g=golf1`).

## Start
npm install
PORT=3001 npm start

## Use
1) Upload a swing video (or click Analyze to see mock metrics).
2) Draw: yellow ground line, green spine line, blue shaft line.
3) Click Analyze → metrics + coaching tips.
4) Export PNG Report → 5-panel strip with angles banner.
